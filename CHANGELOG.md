# Changelog

## 1.0.0 - 2026-10-22

First public release.

- Label setup wizard with common sizes (product, shipping, garment / heat-transfer), 203/300/600 dpi,
  gap / black-mark / continuous media, thermal transfer or direct thermal, mirror, speed, darkness.
- Text (any font or language, or printer fonts), barcodes, QR codes, boxes, lines, ellipses, images.
- Drag, snap, resize, undo / redo, copy / paste, align & distribute.
- Data merge from Excel, CSV, SQLite and ODBC databases with `{Field}` placeholders and formats;
  multiple fields with a custom separator.
- Batch printing: all, current, selected or a range of records; quantity column.
- Multi-up media (2, 3… labels across): next record, same record, or a separate design per label,
  with a live preview of every label in the row.
- Output to Windows printers (RAW), network (port 9100), serial ports or `.prn` files;
  feed / calibrate / self-test.
- Animated mock printer for testing without hardware.
